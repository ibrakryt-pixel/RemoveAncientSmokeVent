# Remove Ancient Smoke Vent

Мод для RimWorld (1.6), позволяющий демонтировать древние дымоотводы (`AncientSmokeVent`) и отключать их эффекты.

---

## 📥 Скачать мод / Download Mod

(https://github.com/ibrakryt-pixel/RemoveAncientSmokeVent/releases/latest/download/RemoveAncientSmokeVent.zip)

---

## 🛠️ Инструкция по установке / Installation

1. Скачайте `.zip` архив по ссылке выше.
2. Распакуйте папку `RemoveAncientSmokeVent` в директорию модов вашей игры:
   `RimWorld/Mods/`
3. Включите мод в меню игры (требуется **Harmony**).
